# Projet d'Algorithmes

## Description

Ce projet contient différents scripts Python permettant d'implémenter et de résoudre plusieurs problèmes à l'aide de différents algorithmes.

L'objectif est de développer la logique algorithmique, la capacité de résolution de problèmes et les compétences en programmation Python, tout en cherchant à produire des solutions efficaces.

## Requirements

### Général

* Éditeurs autorisés : `vi`, `vim`, `emacs`
* Tous les fichiers seront interprétés/exécutés sur Ubuntu 14.04 LTS avec Python 3 (version 3.4.3)
* Tous les fichiers doivent se terminer par une nouvelle ligne
* La première ligne de chaque fichier Python doit être exactement :

```python
#!/usr/bin/python3
```

* Tous les fichiers doivent être exécutables
* Le code doit être documenté
* Le code doit respecter le style PEP 8 (version 1.7.x)

## Utilisation

Rendre un fichier Python exécutable :

```bash
chmod +x nom_du_fichier.py
```

Exécuter un script :

```bash
./nom_du_fichier.py
```
