# 0. Détection de cycle dans une liste chaînée

## Objectif
Écrire une fonction en C qui vérifie si une liste chaînée contient un cycle.

## Prototype
```c
int check_cycle(listint_t *list);
```

## Retour
- `0` : aucun cycle.
- `1` : un cycle est détecté.

## Contraintes
- Utiliser uniquement les fonctions autorisées : `write`, `printf`, `putchar`, `puts`, `malloc` et `free`.
- Privilégier une solution efficace en temps et en mémoire.
- Commencer par réfléchir à la solution au tableau (*whiteboard first*).
- Aucun recours à Google pendant la préparation.
